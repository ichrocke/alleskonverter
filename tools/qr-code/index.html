    Gut zu wissen

    Dieser QR-Code-Generator beherrscht zwölf Inhaltstypen — vom einfachen Link über WLAN-Zugangsdaten und Visitenkarten (vCard) bis zum GiroCode für Überweisungen. Gestalten lässt sich alles: Punktstile, Farben und Verläufe, ein Logo in der Mitte oder ein ganzes Bild im Code, dazu Rahmen mit eigenem Text. Der Export geht als PNG, SVG, JPEG oder WebP bis 4096 px.

    Werden meine Daten hochgeladen?

    Nein. Der Code entsteht vollständig in deinem Browser — auch WLAN-Passwörter oder Kontaktdaten, die du eingibst, verlassen dein Gerät nicht. Der Verlauf wird nur lokal in deinem Browser gespeichert und lässt sich jederzeit löschen.

    Bleibt der QR-Code für immer gültig?

    Ja. Die Daten stecken direkt im Code, nicht auf einem Server — es gibt keine Weiterleitung, die ablaufen könnte, und kein Abo. Einmal erstellt, funktioniert der Code dauerhaft.

    Ist der Code mit Logo oder Bild noch scanbar?

    Ja — beim Einsatz von Logo oder Bild-im-Code wird die Fehlerkorrektur automatisch auf „Hoch“ gesetzt. Vor dem Drucken empfiehlt sich trotzdem ein kurzer Test mit der Handykamera.
