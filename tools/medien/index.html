    So funktioniert es: Das Werkzeug nutzt ffmpeg als WebAssembly — dieselbe Software, die auch Profi-Tools verwenden, nur im Browser. Deine Datei bleibt trotzdem lokal: Heruntergeladen wird nur das Programm, nie deine Daten hochgeladen. Videokonvertierung ist spürbar langsamer als am Rechner installierte Programme — für Alltagsdateien reicht es gut. Wird ein Video als Audioformat (z. B. MP3) ausgegeben, wird automatisch nur die Tonspur übernommen.
