Gut zu wissen

README schreiben, Blogartikel vorbereiten, HTML-Schnipsel in Markdown übernehmen: Dieses Werkzeug wandelt in beide Richtungen und zeigt das Ergebnis live beim Tippen. Die Vorschau lässt sich an der Ecke aufziehen, in einem eigenen Tab öffnen oder gleich im großen Editor bearbeiten — links Markdown, rechts die fertige Seite, die Teilung dazwischen frei verschiebbar. Die erzeugte HTML-Seite nutzt die volle Fensterbreite.

Werden meine Dateien hochgeladen?

Nein. Die Verarbeitung läuft vollständig lokal in deinem Browser — es gibt keinen Server, der Dateien annehmen könnte. Deine Dateien verlassen dein Gerät zu keinem Zeitpunkt.

Welcher Markdown-Dialekt wird unterstützt?

GitHub-üblicher Markdown: Überschriften, Listen, Links, Bilder, Code-Blöcke, Tabellen, Zitate. Gerendert wird mit der bewährten Bibliothek marked.

Welche Ausgabeformate gibt es?

Aus Markdown wird wahlweise eine komplette HTML-Datei, ein HTML-Fragment zum Einbetten oder reiner Text (.txt); die Gegenrichtung liefert Markdown (.md). Über den Drucken-Knopf des großen Editors lässt sich die fertige Seite außerdem als PDF sichern, und eine Word-Datei (DOCX) erzeugt das nach dem Umwandeln verlinkte Werkzeug „Word-Datei erstellen“.

Was geht bei HTML → Markdown verloren?

Alles, was Markdown nicht kennt: Formulare, Skripte, komplexe Layouts und Styling. Der Textinhalt mit seiner Struktur bleibt vollständig erhalten.

Was kostet das? Brauche ich ein Konto?

Nichts und nein. Alle Werkzeuge auf alleskonverter.de sind kostenlos, ohne Registrierung und ohne Limits bei Dateigröße oder Anzahl nutzbar.

Markdown → HTML nutzt marked, die Gegenrichtung turndown. Bei HTML → Markdown gehen Dinge verloren, die Markdown nicht kennt (Formulare, Skripte, komplexe Layouts) — der Textinhalt bleibt vollständig erhalten.
