Gut zu wissen

Der Export aus dem Onlinebanking kommt als CSV, das Tool will aber JSON — oder umgekehrt? Dieses Werkzeug liest CSV, TSV, JSON, XLSX und das alte XLS, zeigt eine Vorschau und wandelt ins Wunschformat. Für deutsches Excel gibt es das Semikolon-Trennzeichen und eine UTF-8-Kennung, damit Umlaute korrekt ankommen.

Werden meine Dateien hochgeladen?

Nein. Die Verarbeitung läuft vollständig lokal in deinem Browser — es gibt keinen Server, der Dateien annehmen könnte. Deine Dateien verlassen dein Gerät zu keinem Zeitpunkt.

Warum zeigt Excel meine Umlaute kaputt an?

Klassisches CSV-Problem: Excel erwartet eine UTF-8-Kennung (BOM) am Dateianfang. Die hängt dieses Werkzeug automatisch an — und mit Semikolon als Trennzeichen öffnet deutsches Excel die Datei direkt richtig.

Wie muss mein JSON aussehen?

Als Liste von Objekten: jedes Objekt eine Zeile, die Schlüssel werden zu Spaltennamen — das übliche Format von API-Exporten. Auch eine Liste von Listen (Zeilen als Arrays) wird verstanden.

Was kostet das? Brauche ich ein Konto?

Nichts und nein. Alle Werkzeuge auf alleskonverter.de sind kostenlos, ohne Registrierung und ohne Limits bei Dateigröße oder Anzahl nutzbar.

JSON wird als Liste von Objekten gelesen und geschrieben (eine Zeile = ein Objekt, Spaltennamen aus der ersten Zeile). CSV-Dateien bekommen eine UTF-8-Kennung (BOM), damit Excel Umlaute korrekt anzeigt.
