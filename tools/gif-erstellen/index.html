    Gut zu wissen

    Ein paar Fotos zu einer kleinen Animation machen — für eine Nachricht, eine Anleitung Schritt für Schritt oder einen Vorher-Nachher-Vergleich. Die Bilder werden in der gewählten Reihenfolge aneinandergehängt, das Tempo bestimmst du. Gerechnet wird mit ffmpeg, das eine eigens erzeugte Farbtabelle verwendet — dadurch sehen die Farben deutlich besser aus als bei der Standardumwandlung.

    Werden meine Bilder hochgeladen?

    Nein. Einmalig wird das Konverter-Programm von dieser Website geladen (rund 31 MB); die Bilder selbst bleiben auf deinem Gerät.

    Warum wird das GIF so groß?

    GIF stammt aus den Achtzigern und kennt keine moderne Kompression. Jedes Einzelbild kostet Platz. Wirksam sind: kleinere Breite, weniger Bilder pro Sekunde und insgesamt weniger Einzelbilder. Für längere Sequenzen ist ein MP4 oder WebM um ein Vielfaches kleiner — das erzeugt Audio & Video.

    Wie viele Bilder sind sinnvoll?

    Für eine flüssige kurze Schleife etwa 10 bis 30. Bei mehr als 50 wird die Datei schnell mehrere Megabyte groß.

    Was kostet das? Brauche ich ein Konto?
