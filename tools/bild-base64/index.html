Gut zu wissen

Ein Daten-URI ist ein Bild, das nicht als eigene Datei liegt, sondern als lange Zeichenkette direkt im Code steht. Das ist praktisch für kleine Symbole in einer CSS-Datei, für ein Logo in einer E-Mail-Signatur oder überall dort, wo man keine zusätzliche Datei hochladen kann oder will.

Wann lohnt sich das — und wann nicht?

Faustregel: bis etwa 10 KB ja, darüber selten. Kleine Bilder sparen eine zusätzliche Serveranfrage. Große Bilder blähen dagegen den Code auf, werden nicht mehr getrennt zwischengespeichert und machen die Seite eher langsamer. Base64 vergrößert die Daten außerdem um rund ein Drittel.

Wird mein Bild hochgeladen?

Nein. Die Umwandlung passiert vollständig in deinem Browser.

Funktioniert das in E-Mails?

Gemischt. Apple Mail und viele Handy-Programme zeigen Daten-URIs an, Outlook und Gmail blockieren sie oft. Für Signaturen ist ein normal verlinktes Bild verlässlicher — probier es im Zweifel mit einer Testmail an dich selbst.
