Gut zu wissen

Eine Bildergalerie in eine Seite einzubauen ist erstaunlich fummelig: Man braucht die richtigen CSS-Regeln, muss an die Bildunterschriften denken, an die alt-Texte für Screenreader und daran, dass die Bilder nicht in Originalgröße ausgeliefert werden. Hier ziehst du deine Bilder hinein, sortierst sie und bekommst einen fertigen Schnipsel — sauberes HTML mit CSS, das ohne Framework und ohne Bibliothek auskommt.

Werden meine Bilder hochgeladen?

Nein. Die Bilder werden von deinem Browser gelesen, verkleinert und wieder in eine Datei geschrieben. Es gibt keinen Server, der sie annehmen könnte.

Soll ich die Bilder einbetten oder daneben ablegen?

Eingebettete Bilder (als data:-Adresse) ergeben eine einzige HTML-Datei, die man per E-Mail verschicken oder auf einen Stick legen kann — dafür wird sie schnell mehrere Megabyte groß, und der Browser kann nichts zwischenspeichern. Für eine echte Webseite ist die zweite Variante besser: Du bekommst ein ZIP mit der HTML-Datei und einem Ordner bilder/ und lädst beides zusammen hoch.

Braucht die Galerie JavaScript?

Nur die Großansicht beim Anklicken, und die sind rund fünfzehn Zeilen. Schaltest du sie ab, ist das Ergebnis reines HTML und CSS — das lässt sich auch in CMS-Systeme, Wikis und Newsletter einsetzen, die kein JavaScript durchlassen.

Was ist mit den alt-Texten?

Jede Bildunterschrift, die du einträgst, wird gleichzeitig als alt-Text gesetzt. Lässt du sie leer, bekommt das Bild ein leeres alt="" — das ist die richtige Kennzeichnung für rein dekorative Bilder, damit Screenreader sie überspringen statt Dateinamen vorzulesen.
